# Thumbnail Regenerator

v1.1.0

Reliably regenerate thumbnails for all images in your shop.

## Installation

_Thumbnail Regenerator_ is installed like any other module. Simply upload your archive to install it.

## Usage

_Thumbnail Regenerator_ is a tool that allows you to regenerate thumbnails of images. It does not matter how many images you have in your shop, this module will regenerate all of them quickly and without timeout errors. You can either choose to generate thumbnails of all images or choose a specific image group. (categories, manufacturers, products, etc.) You can also specify which thumbnail types should be generated.

Click __Start__ to regenerate all thumbnails in the corresponding image group. Click __Stop__ to pause and __Resume__ to continue regeneration from where you left off.

If you experience errors during thumbnail generation, try lowering the number of images that are processed at once. Available values range from 1 to 10. Greater values will generally increase thumbnail generation speed but may lead to timeouts on slower servers.
