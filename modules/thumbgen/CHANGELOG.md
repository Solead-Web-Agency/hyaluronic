# Changelog

## 1.1.0 - 2019-09-21

- Add a slider for customizing the number of images processed at once.
- Make it easy to regenerate thumbnails of images that have previously been skipped due to insufficient memory.
- Add thumbnail generation log.
- Add compatibility with PrestaShop 1.6.
- Minor improvements and bug fixes.

## 1.0.1 - 2019-09-16

- Fix a PrestaShop debug mode error that appears if no thumbnails have been generated in at least one image group.

## 1.0.0 - 2019-09-10

- Initial release.
