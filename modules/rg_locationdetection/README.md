Advanced Location Detection - Module for PrestaShop (1.5.x - 1.7.x)
==================================================
## Description
Detect the country and language of your visitors and configure redirects, default customer language, currency and carrier, besides other actions.

## Requirements
- [PrestaShop 1.5.x - 1.7.x](https://www.prestashop.com/)
- [Free account in IP2Location](https://lite.ip2location.com/)
- [PHP 5.4+](http://www.php.net/)
- [PHP cURL extension](http://php.net/manual/en/book.curl.php)
