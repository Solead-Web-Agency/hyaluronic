Chaque code de transparence est un code unique, alphanumérique et non séquentiel imprimé sous la forme d'un petit code-barres carré sur l'emballage de votre produit. La transparence est la seule entité qui possède et a accès au protocole de génération de code. De plus, Transparency conserve un enregistrement de chaque code généré avec le produit pour lequel il a été généré et utilise les informations pour authentifier les produits.
